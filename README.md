# Тетрис (консольная версия, C#)

Классический тетрис, который работает прямо в консоли. Написан на C# в учебных целях.

## Что умеет игра

- Семь стандартных фигур тетриса, у каждой можно менять положение поворотом.
- Поле 10 на 20 клеток. Фигуры падают, их можно двигать влево и вправо, ускорять и сбрасывать вниз.
- Заполненные линии удаляются, за них начисляются очки.
- Справа от поля показывается следующая фигура.
- Клетки поля рисуются так, чтобы выглядеть квадратными в консоли.
- Есть главное меню: новая игра, таблица рекордов, выход.
- Рекорды сохраняются в файл и показываются отдельной таблицей.
- Когда фигурам больше некуда падать, игра заканчивается и предлагает начать заново.

## Управление

 - Клавиши | Действие
 - ← → - движение влево и вправо 
 - ↑ - поворот фигуры 
 - ↓ - ускорить падение 
 - Пробел - сбросить фигуру вниз 
 - Esc - выйти из партии или из меню 
 - 1 / 2 / 3 - выбор пункта меню 
 - Y - начать заново после проигрыша 

## Из чего состоит проект

 Название файла - Что делает 
- Program.cs - запускает игру 
- Tetromino.cs - фигуры тетриса, их поворот и копирование 
- GameField.cs - игровое поле: проверка, куда можно поставить фигуру, удаление линий, отрисовка 
- TetrisGame.cs - меню, игровой цикл, управление, счёт и рекорды 
- ScoreManager.cs - сохранение и показ таблицы рекордов 
- README.md - описание проекта
